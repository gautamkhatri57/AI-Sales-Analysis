# 📊 Sales Data Analysis Dashboard

## 📌 Project Overview

The **Sales Data Analysis Dashboard** is a Python-based data analytics project developed using **Streamlit**, **Pandas**, and **Matplotlib**. It allows users to upload a sales dataset in CSV format and analyze sales performance through interactive charts and key performance indicators (KPIs).

This project helps businesses understand sales trends, product performance, and city-wise revenue using an easy-to-use dashboard.

---

## 🚀 Features

* 📂 Upload Sales CSV File
* 👀 Dataset Preview
* 💰 Total Revenue
* 🛒 Total Orders
* 📦 Total Products
* 📈 Monthly Sales Analysis
* 🏆 Top Selling Products
* 🌍 City-wise Sales Distribution (Pie Chart)
* 📊 Interactive Dashboard

---

## 📥 Installation

Clone the repository:

```bash
git clone https://github.com/your-username/Sales-Data-Analysis.git
```

Go to the project folder:

```bash
cd Sales-Data-Analysis
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
